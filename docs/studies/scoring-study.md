# Scoring study (OPEN-2, OPEN-3)

The measurement that chose the scoring defaults in README §7 (SM-SCORE-001, -011 to -014). It was
produced by `tools/SecretModel.ScoringStudy` on 2026-11-25 in Claude's cloud Linux workspace (.NET SDK
10.0.404). The study is deterministic: rerunning it gives the same tables.

```
dotnet run -c Release --project tools/SecretModel.ScoringStudy
```

## Setup

- **Shoppers:** `SyntheticShopper` seeds 1–10 (`tools/SecretModel.Synthetic`). Each has three habit
  modes (routine, evening, weekend) with their own merchant groups, amount band, time buckets and
  online rate. Habits use merchant groups 0–5 and amount bins 0–5 only.
- **Per shopper:** a journal of 300 transactions (other lengths in section 3) builds the profile. It
  is then scored on the next 300 habitual purchases and 100 anomalies of each kind:
  - **random**: any of the 512 symbols
  - **takeover**: ATM, travel or online market, amount bin 6–7, mostly online and at night
  - **subtle**: a habitual purchase with one feature changed, which is sometimes still habitual
- **AUC:** the chance that an anomaly's `fraud_score` beats a normal purchase's; ties count half. The
  overall AUC is the mean of the three kinds, which equals the AUC of all anomalies pooled.
- **Verdict shares:** REVIEW+ is REVIEW or FRAUD_SUSPECTED.
- **Synthetic data only.** These numbers compare designs; they don't predict performance on real cards.
